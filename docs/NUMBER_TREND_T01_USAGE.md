# T01 토큰 사용량 측정

대상은 T01 회차·본번호·보너스 검증 구현과 직접 검증이다. 로컬 세션의 token_count 누적 계수에서 요청 직전 값과 아래 측정 시점 값의 차이를 계산했다.

측정 구간은 2026-11-11T04:11:46.339Z부터 2026-11-11T04:13:39.025Z까지다. 이 문서 생성과 이후 최종 답변은 다음 계수 갱신에 포함될 수 있어 이번 수치는 해당 시점의 스냅샷이다.

| 항목 | 토큰 |
|---|---:|
| 전체 입력 | 808,713 |
| 캐시 입력, 전체 입력에 포함 | 805,248 |
| 캐시 제외 입력 | 3,465 |
| 출력 | 4,207 |
| 전체 입력 + 출력 | 812,920 |
| 캐시 제외 입력 + 출력 | 7,672 |

추론 출력 계수는 765이며 출력 합계에 포함된다. 중복해서 더하지 않는다. 전체 처리량과 캐시 제외 합계를 함께 기록해 긴 대화 재입력의 영향을 확인한다. 캐시 입력도 실제 처리량과 한도 산정에 영향을 줄 수 있으며 계정 한도와 비용 환산은 사용량 화면에서 확인한다.

T01은 계획상 2점이므로 이번 캐시 제외 합계를 단순 환산하면 1점당 약 3,836토큰이다. 한 개 데이터 검증 태스크의 관측값이며 향후 UI·통합 작업의 예산은 추가 측정으로 보정한다. 계정의 5시간 한도 잔여율과 현재 컨텍스트는 이 누적 계수에서 직접 산출할 수 없다.

검증 결과는 관련 테스트 24개 통과, 실제 배포 CSV 649개 회차 통과다. 상세 작업 완료는 1/18이며 다음 작업은 T02다.
