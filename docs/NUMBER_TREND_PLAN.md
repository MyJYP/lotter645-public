# 재미로 보는 번호 차트 기획서

기획 작성일 2026-11-11. 공개 앱 `lotter645-public`의 v6.2.5에서 설계했고, 출현 흐름·당첨금 배분·보너스 화면과 계산 구현 및 통합 검증을 완료했다. 현재 진행·배포 상태는 작업 목록을 기준으로 확인한다. 아래는 기획 당시 명세와 구현 전 시안 기록이다.

구현 함수·데이터 계약·화면 연결은 [핵심 구현 설계](NUMBER_TREND_DESIGN.md)에 정리했다.

120회선에 대한 추가 요청을 반영해 5·10·20·60·120회선을 선택할 수 있도록 확장했다. 5·20·60·120회선을 기본 표시한다. 실제 보유 데이터로 만든 [인터랙티브 화면 구성안](previews/number-trend.html), [데스크톱 화면](previews/number-trend-desktop.png), [모바일 화면](previews/number-trend-mobile.png)을 제공한다. 이 미리보기는 독립 HTML이며 공개 앱에 통합하는 단계는 예정 상태다. 주변 메뉴·탭은 배치 예시이고 번호·기간·선 선택과 표의 번호 선택이 동작한다.

## 목적

1~45번 각각의 과거 출현 기록을 주식 차트처럼 살펴보는 체험 섹션을 만든다. 사용자는 번호를 고르고 5·10·20·60·120회 출현률, 5회선·20회선의 교차, 실제 출현 시점을 비교한다. 여러 번호의 흐름을 살펴보는 재미와 계산 과정의 이해가 목적이다.

화면 제목은 **재미로 보는 번호 차트**로 정한다. 설명은 “관심 있는 번호의 짧고 긴 출현 흐름을 함께 살펴보세요.”로 쓴다. 차트 아래에는 “과거 본번호 출현률을 보여줍니다. 공정하고 독립적인 추첨에서 모든 6개 조합의 당첨 확률은 같습니다.”를 표시한다.

## 화면 위치와 이용 흐름

공개 앱의 **데이터 탐색 → 재미로 보는 번호 차트** 탭으로 배치한다. 현재 데이터 탐색에는 기본 통계·시계열 분석·패턴 분석의 세 탭이 있어 네 번째 탭으로 연결할 수 있다.

1. 탭을 열면 보유 데이터의 시작 회차·마지막 회차·마지막 추첨일을 확인한다.
2. 관심 번호를 1~45 중 하나 선택한다. 초기 번호는 1번으로 정한다.
3. 표시 기간을 최근 50회·100회·200회·전체 중에서 고른다. 기본값은 최근 100회다.
4. 선택 번호의 5·20·60·120회 출현률과 5회선·20회선의 차이를 확인한다. 체크박스로 각 선을 켜고 끌 수 있고 10회선을 추가할 수 있다.
5. 차트에 마우스를 올리거나 터치해 해당 회차의 출현 여부와 계산값을 본다.
6. 전체 번호 요약표에서 다른 번호를 비교하고 계산 방법·출처를 확인한다.

모바일에서는 선택 항목과 요약 값을 세로로 배치하고 차트 너비를 화면에 맞춘다. 색상과 함께 선 이름·모양·교차 설명을 표시한다.

### 화면 구성안

```text
재미로 보는 번호 차트
보유 데이터 {시작}~{마지막}회 · 마지막 추첨일 {날짜}

관심 번호 [1 ▼]       표시 기간 [최근 100회 ▼]

최근 5회 출현률   최근 20회 출현률   최근 60회 출현률   최근 120회 출현률
{값}%            {값}%              {값}%              {값}%

[표시할 선 선택 — 5회 / 10회 / 20회 / 60회 / 120회]
[회차별 이동평균 출현률 차트]
[실제 출현 회차 표시와 상향·하향 교차 표시]

{마지막 회차}회 기준 {선택 번호}번의 흐름 설명

[전체 45개 번호의 출현률·차이·교차 요약표]

과거 본번호 출현률과 동일한 조합 확률에 대한 안내
계산 방법 펼치기
데이터 출처 · 이동평균 참고 자료
```

## 지표와 계산 규칙

회차 `t`의 본번호에 번호 `n`이 있으면 `x(n,t)=1`, 관측한 본번호에 없으면 `0`으로 둔다. 보너스 번호는 별도 컬럼으로 보관하며 이 지표의 입력은 본번호 6개로 한정한다.

| 지표 | 계산 | 화면 해석 |
|---|---|---|
| 5회 출현률 | 최근 연속 5회 `x`의 합 ÷ 5 × 100 | 최근 5회 중 해당 번호가 나온 비율 |
| 20회 출현률 | 최근 연속 20회 `x`의 합 ÷ 20 × 100 | 최근 20회 중 해당 번호가 나온 비율 |
| 10·60·120회 출현률 | 최근 연속 N회 `x`의 합 ÷ N × 100 | 각 기간의 출현 비율. 120회는 주 1회 추첨 기준 약 2년 4개월 |
| 출현률 차이 | 5회 출현률 − 20회 출현률 | 단기와 중기 관측 비율의 차이, 단위 `%p` |
| 상향 교차 | 직전 차이 ≤ 0이고 현재 차이 > 0 | 이번 회차에서 5회선이 20회선 위로 이동 |
| 하향 교차 | 직전 차이 ≥ 0이고 현재 차이 < 0 | 이번 회차에서 5회선이 20회선 아래로 이동 |
| 이론 기준선 | `6/45 × 100 ≈ 13.33%` | 공정한 추첨에서 번호 하나가 본번호에 포함될 확률 |

5회 중 2회 출현했다면 5회 출현률은 40%다. 이는 해당 과거 구간에서 관측한 비율이다. 두 선이 위아래에 있는 상태와 이번 회차에 새로 교차한 사건은 각각 “5회선이 위에 있음”과 “이번 회차 상향 교차”로 표시한다. 두 값이 같으면 “두 선이 같음”으로 표시한다.

시간축은 회차, 세로축은 출현률 0~100%다. 선택한 이동평균선과 13.33% 기준선을 표시하고, 실제 출현은 차트 하단의 점으로 표시한다. 교차 표시는 5회선·20회선을 모두 선택했을 때 해당 회차의 5회선 위치에 올린다. 자료가 없는 구간은 선을 끊는다.

전체 요약표는 기본적으로 번호 오름차순으로 제공한다. 열은 번호, 5·20·60·120회 출현률, 5회·20회 차이(%p), 이번 회차 교차 상태로 구성한다. 번호를 선택하면 차트가 바뀐다. 앱 통합 시 열 정렬도 제공한다.

### 데이터 경계 처리

- 전체 관측 이력을 회차 오름차순으로 정렬한 다음 이동평균을 계산하고, 마지막에 화면 표시 기간을 잘라낸다. 최근 50회를 고르더라도 120회선의 차트 시작점 계산에 앞선 119회의 자료를 사용한다.
- N회선은 연속 N회의 자료가 확보된 시점부터 표시한다. 교차 판단은 현재와 직전 회차의 5회·20회 이동평균이 모두 유효한 경우에 한다.
- 누락 회차는 결측값으로 유지한다. 해당 회차가 계산 창에 포함되면 그 이동평균은 “자료 부족”으로 표시한다. 누락을 미출현 0으로 바꾸면 통계가 왜곡되므로 결측 상태를 계산 결과에 전달한다.
- 중복 회차와 잘못된 본번호는 기존 `normalize_draw_history()` 검증을 활용해 오류를 알린다. 빈 자료에는 “표시할 당첨 자료가 없습니다.”를 표시한다.
- 교차 계산은 반올림 전 값으로 수행한다. 정수 형태인 `4 × 최근 5회 출현 횟수 − 최근 20회 출현 횟수`의 부호를 사용하면 소수점 오차 없이 같은 판단을 할 수 있다.
- 화면의 분석 기준은 실제 로드한 마지막 회차다. 작성 시 확인한 배포 CSV는 601~1249회, 총 649개 회차이며 중간 누락이 없다.

## 출처와 표기 문구

데이터 출처와 방법론 출처를 차트 하단에 항상 보이는 링크로 제공한다. 자세한 수식은 접을 수 있는 “계산 방법” 안에 둔다.

- **당첨 데이터** 문구는 “동행복권 회차별 당첨번호를 바탕으로 구성한 배포 데이터를 사용합니다.”로 정한다. 보유 회차 범위와 마지막 추첨일을 함께 표시한다. [동행복권 회차별 당첨번호](https://www.dhlottery.co.kr/lt645/winNumber)
- **이동평균 참고** 문구는 “일정 기간 값의 평균과 단기·장기 이동평균 교차 개념을 참고했습니다.”로 정한다. Fidelity 자료는 단순이동평균과 두 이동평균의 교차를 설명한다. [Fidelity의 Simple Moving Average 설명](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)
- **기간 선택 참고** 문구는 “5·10·20·60·120 기간은 주식 이동평균에서 참고했습니다.”로 정한다. 키움증권은 이 다섯 기간을 많이 쓰는 이동평균선으로 안내한다. 주식 일봉의 120일은 거래일 기준 약 반년이고, 로또의 120회는 약 2년 4개월이다. [키움증권 기술적 지표 안내](https://www1.kiwoom.com/wm/fnd/fs010/fndTechIndiGuidePop)
- **앱의 적용 방식** 문구는 “번호별 출현을 0과 1로 기록하고 회차별 이동평균으로 표현한 방식은 이 앱의 재미용 분석 규칙입니다.”로 정한다. 로또 적용 방식은 이 기획에서 선택했다.

대화에서 언급한 유튜브 영상의 제목과 구체적인 규칙은 확인 전이다. 특정 투자자의 이름이나 ‘공인된 로또 알고리즘’이라는 표현을 붙이려면 별도의 원문 근거가 필요하다. 현재 기획의 출처는 위 공식 데이터와 일반 이동평균 설명으로 명시한다.

## 후속 체험 확장

첫 화면의 출현률·교차를 확인한 뒤에는 사용자가 마음에 드는 흐름을 지정해 6개 번호를 뽑는 체험으로 확장할 수 있다. 이름은 “차트 취향으로 6개 뽑기”로 제안한다. 이 확장은 후속 구현 항목이며 가중치·동점 처리·연속 추출 규칙을 정한 별도 명세가 필요하다.

후속 점수는 **사용자 패턴 선호도 점수(Pattern Preference Score)**, 제한 조건은 **패턴 필터 조건**으로 표시한다. 예를 들어 상향 교차 선호, 단기 출현률 선호를 선택하면 그 취향에 맞는 번호를 추출하도록 설계한다. 추출 결과에는 적용한 선호와 관측 통계를 보여준다.

지표를 확대한다면 출현 간격과 두 번호의 동반 출현을 다음 후보로 검토한다. 여러 지표를 조합한 결과를 평가할 때는 회차 `t`까지의 자료로 규칙을 정하고 `t+1`을 평가하는 순차 검증을 적용한다. 동일한 게임 수의 무작위 선택과 비교하고, 조정에 사용하지 않은 기간에서 확인한 결과와 실험 기간·횟수를 함께 공개한다.

## 구현 순서와 완료 기준

1. 검증된 과거 데이터로 번호별 0·1 시계열, 5·10·20·60·120회 출현률, 5회·20회 교차 결과를 계산한다.
2. 데이터 탐색 탭과 차트를 연결하고 실제 출현·자료 부족·동률 상태를 표시한다.
3. 하단에 계산 설명과 클릭 가능한 출처를 넣고 모바일 화면을 확인한다.
4. 아래 검증을 통과한 뒤 버전 증가, 커밋·푸시, 공개 페이지 표시를 확인한다.

| 검증 항목 | 통과 조건 |
|---|---|
| 출현률 검산 | 최근 5회 중 2회 출현은 40%, 최근 20회 중 3회 출현은 15% |
| 교차 | 직전 차이 0 이하 → 현재 양수는 상향 교차, 그 반대는 하향 교차. 같은 방향 상태의 지속은 교차 없음 |
| 초기 자료 | 4회 자료에서 5회선은 자료 부족, 19회에서 20회선은 자료 부족, 연속 20회에서 20회선 첫 값 표시 |
| 장기선 | 연속 119회에서 120회선은 자료 부족, 연속 120회에서 첫 값 표시. 10회·60회도 같은 경계 검증 |

## 추가 기획 — 번호별 당첨금 배분 누계

사용자가 제안한 “해당 회차의 당첨금 120억 원을 본번호 6개에 각 20억 원씩 배분”하는 방식을 적용한다. 화면 이름은 **번호별 당첨금 배분 누계**로 제안한다. 설명은 “각 회차의 1등 당첨금을 본번호 6개에 똑같이 나눠 누적한 분석용 금액입니다.”로 정한다. 균등 배분은 사용자가 제안한 집계 규칙이며, 번호별 인과적 기여도를 추정하려면 별도의 정의와 근거가 필요하다.

### 금액 기준

기본값은 **1등 총액 기준**으로 제안한다. 현재 배포 CSV의 `1등 당첨액`은 1게임당 금액이고, `1등 당첨자수`는 집계에 사용할 당첨게임 수다. 공식 결과 페이지도 등위별 총 당첨금, 당첨게임 수, 1게임당 당첨금을 제공한다. [동행복권 추첨 결과](https://www.dhlottery.co.kr/lt645/result)

`회차 총액 = 1게임당 1등 당첨금 × 1등 당첨게임 수`

`번호별 회차 배분액 = 해당 번호가 본번호이면 회차 총액 ÷ 6, 그 밖에는 0`

`번호별 배분 누계 = 선택한 회차 범위의 번호별 회차 배분액 합계`

공식 총액을 직접 확보한 경우에는 공식 총액을 우선 사용하고, 게임당 금액을 곱한 재구성 값은 계산 근거를 표시한다. 지급 완료 여부와 세후 수령액은 이 집계에서 추정할 수 없으므로 화면 단위는 **공시 당첨금 기준·세전**으로 명시한다.

“1게임당 금액 기준”도 선택할 수 있게 한다. 이 모드의 회차 배분액은 1게임당 금액을 6으로 나눈 값이다. 선택한 기준을 차트와 표 제목에 함께 표시한다. 기본 총액 기준에서는 판매 규모·이월금이, 게임당 기준에서는 당첨게임 수까지 순위에 영향을 준다.

### 화면과 계산 경계

- 상단에 금액 기준, 집계 기간, 비교할 번호 최대 6개를 선택한다. 기간은 전체 보유 회차·최근 120회·최근 60회로 시작한다.
- 번호 1~45의 누계 순위, 선택 번호의 누적선, 출현 횟수, 출현 회당 평균 배분액을 제공한다. 누계는 선택한 기간의 시작점에서 0으로 시작한다.
- 누적선은 금액이 더해질 때만 증가한다. 변화하는 흐름은 별도의 **최근 N회 배분액 합계**로 표시할 수 있다. 이는 최근 구간에서 빠지는 과거 금액에 따라 내려갈 수도 있다.
- 회차 상세를 펼치면 본번호 6개, 1게임당 당첨금, 당첨게임 수, 사용한 총액, 6등분 금액을 함께 보여준다.
- 6등분은 유리수 또는 충분한 정밀도로 계산하고 마지막 화면 표시에서 반올림한다. 번호마다 원 단위 절사 후 더하면 합계가 달라지므로 누계 계산은 반올림 전에 수행한다.
- 누락 금액은 집계에서 제외하고 제외 회차 수를 표시한다. 유효한 0원과 결측값을 구분한다. 당첨게임이 없는 회차의 실제 배분액은 0으로 두고 이월 금액은 당첨게임이 발생한 회차에서 집계한다.
- 검증에서는 모든 번호의 배분액 합계가 해당 기간에 사용한 회차 총액 합계와 일치해야 한다. 120억 원·본번호 1~6의 예시에서는 1~6번 각각 20억 원, 7~45번은 0원이어야 한다.
