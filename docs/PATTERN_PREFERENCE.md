# 패턴 선호도 1세트 연속 추출

2026-11-11 구현. `번호 추천` 화면의 기본 모드인 `패턴 선호도 1세트 연속 추출`에서 사용한다.

- 동반/상극 쌍, 연속수·이월수·주기, 구간 분포, 용지 그리드를 실제로 채점한다.
- 사용자 패턴 선호도 점수(Pattern Preference Score)는 과거 패턴과 설정의 적합도이며 당첨확률이 아니다.
- 가중 비복원 샘플링으로 최대 1,000개의 고유 후보를 생성한다. 세션에서 이미 반환한 조합은 제외한다.
- 정상 조건에서는 상위 5% 풀(경계 동점 포함)에서 소프트맥스로 추출한다.
- 후보가 모두 탈락하면 그리드 → 구간 → 상극 쌍 순서로 필터를 해제하고, 처음 후보가 생긴 단계의 최고 점수 조합을 반환한다. 동점은 세션 RNG로 선택한다. 해제한 필터의 점수 계산은 유지한다.
- 번호 범위, 한 세트 내 번호 중복 금지, 세션 전체 조합 중복 금지는 완화하지 않는다.
- 결과에 점수 근거, 가중 기여도, 데이터 범위, 적용 설정, 원래 필터 위반과 단계별 완화 내역을 보관한다.
- 이력은 Streamlit 세션 범위다. 브라우저 세션이 끝나거나 이력을 명시적으로 초기화하면 중복 방지 기록도 초기화된다. 공유 CSV에 자동 저장하지 않는다.

## 데이터·난수·캐시 수정

`회차` 최신순 정렬과 인덱스 초기화를 공통 적용했다. 미출현 기간과 평균 간격은 DataFrame 행 라벨이 아니라 실제 관측 회차의 차로 계산한다. 누락 회차와 미관측 번호는 관측 범위의 한계를 표시한다. 기존 추천기에서도 전역 난수 재설정을 함수별 로컬 RNG로 바꾸었다. 명시 seed는 재현에 사용할 수 있지만 이전 NumPy 난수 방식과 번호 배열이 동일하다는 보장은 하지 않는다.

UI 데이터 캐시는 CSV 내용 해시를 키로 사용한다. 모델·추천기는 `cache_data`로 세션별 복사본을 돌려주며 모델 설정도 키에 포함한다. 새 추출 엔진은 클릭 시 현재 설정으로 구성하고 RNG·이력은 세션에만 둔다.

## 확인

기존 앱 실행 의존성이 설치된 Python 환경에서:

```sh
python -m pip install pytest
python -m pytest tests -q
streamlit run src/web_app.py
```

테스트는 실제 CSV의 999회까지 필터링, 불규칙 인덱스·입력 역순, 네 그룹 점수, 단계적 완화, 연속 100회 중복 방지, 전역 RNG 불변, 9개 기존 전략의 seed 재현성, Streamlit AppTest의 실제 앱 라우팅·설정·이력·세션 격리를 검증한다. 실제 브라우저·운영 서버 배포 검증은 포함하지 않는다.

기존 백테스터 캐시·ROI 정의·과거 전략의 예측 성능 검증은 이 기능의 완료 범위와 별도다. 이 기능을 당첨확률 향상 또는 기대 수익 개선으로 표현하지 않는다.
