# T18 배포 검증

로컬 릴리스 v6.2.29를 준비했다. 독립 최종 리뷰는 커밋 `791841e`의 전체 테스트 184개 통과와 수정 사항 재검증을 확인했다. T17의 실제 앱·데스크톱·390px 모바일·행 선택 검증도 통과했다.

현재 상태는 **공개 배포 검증 완료**다. 릴리스 커밋·푸시 후 실제 버전, 데이터 범위, 세 화면, 예외 표시를 확인하고 결과를 여기에 기록한다.


## 공개 서버 확인 완료

릴리스 커밋 `41850e020d9c59062b80df368072275a12a3f66e`을 푸시했다. 공개 앱이 잠든 상태여서 기동을 요청한 뒤 실제 서버에서 다음을 확인했다.

- v6.2.29 버전 표시와 601~1249회 데이터 범위.
- 실제 데이터 탐색 탭 진입 후 출현 흐름·당첨금 배분·보너스 번호 화면.
- 세 화면의 예외 표시 없음과 브라우저 pageerror 없음.

검증 주소는 https://lotter645-public.streamlit.app/ 이다. 최종 전체 테스트는 184개 통과했고 독립 리뷰의 수정 지적을 해결했다. T18 배포 완료 상태로 기록한다.


## v6.2.30 배포 — 최종 화면 검증 대기

MAC23가 승인한 후보 `43ed21c`의 실행 코드·테스트·의존성·설정·VERSION을 보존한 문서 반영 커밋 `c586dfe`를 origin/main에 푸시했다. 공개 서버에서 v6.2.30과 601~1249회, 출현 흐름 및 금액 화면 렌더링을 확인했고 실행 예외는 없었다.

금액 화면은 이전 “번호별 당첨금 배분 누계” 제목을 표시해 새 제목 검증이 실패했다. 버전 파일과 실행 중 모듈의 갱신 시점이 다른 것으로 추정한다. 엔트리 파일에 주석만 추가한 재배포 트리거 `f25eca1`을 시도했지만 동일 현상이 유지돼 해당 변경을 원복했다. 검토 후보와 실행 파일·테스트·의존성·설정·VERSION이 바이트 단위로 동일한 상태임을 확인했다.

공개 세션의 Main menu는 Print·Record screen만 제공하고 관리자 재시작 기능이 없어, 사용자에게 Streamlit 관리자 화면에서 Reboot app을 요청했다. 관리자 재시작 후 v6.2.30·세 화면·total/per_game 양방향 차트·표 제목 갱신을 확인해야 한다. 현재 판정은 **소스 푸시 완료·공개 제목 최종 검증 대기**다. 이전 v6.2.29 완료 기록은 해당 배포의 이력이다.
