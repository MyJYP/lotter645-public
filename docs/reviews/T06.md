## F01 — P2 기존 오류의 제외 사유 유실

사용자 전달 지적을 재현했다. 원본 음수 금액·잘못된 문자열·소수 당첨게임 수가 준비 단계에서 결측으로 바뀐 후 다시 검증되어 최종 사유가 “자료 없음”으로 바뀌었다.

v6.2.15에서 필드별 제외 사유를 회차 정렬 시 함께 보존하고 최종 사유에 우선 적용했다. 사유 컬럼이 없는 직접 입력은 기존 검증을 사용한다. 1·2등과 총액·게임당 기준의 12개 조합, T08 상세까지 최종 사유 전달, 0게임 예외와 원본 불변성을 검증했다. 관련 테스트 **141개 통과**했다. 개발 재검증 완료이며 독립 재리뷰 결과는 후속 기록한다.
