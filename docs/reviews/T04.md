본번호·보너스 출현 행렬, 1~45 전체 번호, 5·10·20·60·120회 횟수와 출현률, 초기 자료 부족, 누락 회차·보너스 결측, 빈 결과, 입력 정렬과 불변성을 확인했다. 교차와 표시 범위 선택은 T05에서 검토한다.

관련 테스트 **69개 통과**했다. 추가로 다음 독립 검산을 실행했다.

- 로컬 RNG로 170회 범위의 표본을 만들고 중간 회차 2개와 보너스 관측 1개를 누락시켰다.
- 두 모드 각각 10개 기준 회차 × 45개 번호 × 5개 창의 합계 **4,500건**을 회차별 직접 순회 계산과 비교했다. 모든 관측이 있는 창의 값과 결측 창을 확인했다.
- 실제 배포 CSV 601~1249회 649건에서 본번호·보너스 모드 각각 **29,205행**을 확인했다.
- 실제 마지막 회차의 두 모드 × 45개 번호 × 5개 창 **450건**을 CSV 원본에서 직접 집계해 비교했다.

추가 검산에서도 계산 오류를 발견하지 못했다. 입력 역순·비연속 인덱스·미래 자료 추가·입력 불변·N-1/N 경계는 기존 테스트에서 확인했다.
